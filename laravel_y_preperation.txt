 Laravel Request Lifecycle

When a user opens a Laravel URL, the request goes through several steps.

### Flow

1. Request enters `public/index.php`
2. Composer autoload loads dependencies
3. Laravel app bootstraps  
4. Service Providers load
5. Middleware runs
6. Route matches
7. Controller method executes
8. Response returns to browser

-Global Middleware:
------------------ 

php artisan make:Middleware AgeCheck

Then go to folder bootstrap ->app.php and configure the Middleware

$Middleware->append(AgeCheck::class)

now apply condition inside Middleware AgeCheck class function


-Group Middleware:
------------------

Here you can create multiple Middleware and make them into group and use as follows

php artisan make:Middleware AgeCheck
php artisan make:Middleware CountryCheck

Then go to folder bootstrap -> app.php and configure them
$Middleware->appendToGroup('check1',[
    AgeCheck::class,
    CountryCheck::class
]);

Now apply Middleware group "check1" in web.php Route

Route::get('testhere',[HomeController::class,'get_groupmiddleware'])->middleware('check1');

-Route Middleware:
-----------------

You can create middleware and directly apply it inside web.php, then apply it to route, also import it.

COMPONENTS IN LARAVEL :
------------------------

1. `php artisan make:component layout` creates:

   * `app/View/Components/Layout.php`
   * `resources/views/components/layout.blade.php`

2. `<x-layout>` loads `layout.blade.php`.

3. `<x-slot name="title">Home</x-slot>` sends data to `$title`.

4. `<x-slot name="main">...</x-slot>` sends HTML to `$main`.

5. `<x-slot name="login">...</x-slot>` sends HTML to `$login`.

6. In `layout.blade.php`:

```blade
<title>{{ $title ?? 'Home' }}</title>

<div class="content">
    {{ $main ?? '' }}
    {{ $login ?? '' }}
</div>
```

7. When Home page loads, only `$main` is filled.

8. When Login page loads, only `$login` is filled.

9. The layout acts like a common template (header + footer + content area).

10. Think of it as:

```blade
<x-layout>
    Page Content
</x-layout>
```

➡️ Layout = Wrapper
➡️ Slot = Data/content passed into the wrapper.

layout.blade.php is common page 

1. inside this will pass {{$title}} : $title will come another page "homage.blade.php" 

2.homage.blade.php 
     <x-layout>
    <x-slot name="title">Home</x-slot> 
    </x-layout>

In this way you can change related data dynamically

MIGRATION :
-----------

php artisan make:migration create_booking_table

migrate : Keeps existing data, only runs new migrations.(php artisan migrate)

Reset: it will remove all the migration from table (php artisan migrate:reset)

rollback : It will remove the recently created migration (php artisan migrate:rollback)

refresh : Run all migrations again from scratch.(php artisan migrate:refresh)
As a result, all data stored in tables managed by your migrations will be lost

MUTATOR in laravel:
------------------
If you want to change any information before insert to table like to the column name 
(1st letter should capital)->that you can do it in model.

class User extends Model
{
    protected function firstName(): Attribute
    {
        return Attribute::make(
            set: fn ($value) => strtolower($value),
        );
    }
}
