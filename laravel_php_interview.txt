========================================
DAY 1 - PHP BASIC CONCEPTS
========================================

1. GET vs POST
GET:
- Data in URL
- Less secure
- Can be bookmarked

POST:
- Data in body
- More secure
- Used for sensitive data

Example:
$id = $_GET['id'];
$name = $_POST['name'];

----------------------------------------

2. Session vs Cookie

Session:
- Stored on server
- More secure

Cookie:
- Stored in browser
- Less secure

session_start();
$_SESSION['user'] = "John";

setcookie("user", "John", time()+3600);

----------------------------------------

3. Include vs Require

include:
- Warning if file missing
- Script continues

require:
- Fatal error if file missing
- Script stops

include 'file.php';
require 'file.php';

----------------------------------------

4. Echo vs Print

echo:
- Faster
- No return value

print:
- Returns 1

echo "Hello";
print "Hello";

----------------------------------------

5. Variable Scope
- Local
- Global
- Static

global $x;

----------------------------------------

6. OOP Pillars
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction

----------------------------------------

7. Class & Object

class User {
  public $name;
}

$user = new User();

----------------------------------------

8. Constructor

function __construct(){
  echo "Object Created";
}

----------------------------------------

9. Inheritance

class Animal {
  function sound(){
    echo "Sound";
  }
}

class Dog extends Animal {}

----------------------------------------

10. Abstract vs Interface

Abstract:
- Can have methods
- Can have properties

Interface:
- Only method declarations
